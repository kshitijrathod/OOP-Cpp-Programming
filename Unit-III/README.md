# Unit III: Polymorphism

Compile-time and run-time polymorphism, function/operator overloading, virtual functions, abstract classes, polymorphic collections, virtual destructors, object slicing, payment processing and payroll.

## Programs

| # | Program | Brief description |
|---:|---|---|
| 1 | Function Overloading | Demonstrates compile-time polymorphism through overloaded functions. |
| 2 | Area Calculator Using Function Overloading | Calculates square, rectangle and circle areas using overloaded functions. |
| 3 | Unary Minus Operator Overloading | Overloads unary minus for a user-defined Number class. |
| 4 | Prefix and Postfix Increment Operator | Overloads prefix and postfix increment operators. |
| 5 | Binary + Operator Overloading for Complex Numbers | Overloads binary + to add complex numbers. |
| 6 | Relational Operator Overloading | Overloads a relational operator for user-defined Distance objects. |
| 7 | Friend/Non-Member Operator Overloading | Demonstrates operator overloading using a non-member/friend function. |
| 8 | Base Pointer Without a Virtual Function | Shows static binding when a base pointer calls a non-virtual function. |
| 9 | Base Pointer With a Virtual Function | Shows run-time polymorphism through a base pointer and virtual function. |
| 10 | Base Reference With a Virtual Function | Uses a base reference for dynamic dispatch. |
| 11 | Abstract Class and Pure Virtual Function | Creates an abstract class with a pure virtual function. |
| 12 | Collection of Polymorphic Shape Pointers | Processes multiple derived shapes through an abstract base pointer collection. |
| 13 | Virtual Destructor | Shows safe derived destruction through a base pointer. |
| 14 | Object Slicing Demonstration | Demonstrates object slicing and the benefit of references. |
| 15 | Payment Processing System | Implements a polymorphic payment-processing interface. |
| 16 | Employee Payroll Mini-Project | Builds a payroll mini-project using run-time polymorphism. |
