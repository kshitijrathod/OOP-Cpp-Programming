# Unit II: Inheritance

Inheritance concepts including single, multilevel, hierarchical and multiple inheritance, access control, constructor/destructor order, overriding, abstract classes, virtual bases, friend/nested classes, and integrated mini-projects.

## Programs

| # | Program | Brief description |
|---:|---|---|
| 1 | Basic Single Inheritance | Demonstrates Person base class and Student derived class. |
| 2 | Protected Member Access | Shows derived-class access to a protected base member. |
| 3 | Public versus Private Inheritance | Contrasts public and private inheritance accessibility. |
| 4 | Multilevel Inheritance | Builds a Person -> Employee -> Manager inheritance chain. |
| 5 | Hierarchical Inheritance | Uses one Vehicle base class for multiple derived classes. |
| 6 | Multiple Inheritance | Combines two base classes in a derived class. |
| 7 | Resolving Multiple-Inheritance Ambiguity | Resolves same-name base member ambiguity using scope resolution. |
| 8 | Constructor and Destructor Order | Shows base-before-derived construction and reverse destruction. |
| 9 | Parameterized Base Constructor | Initializes a base-class part from a derived constructor. |
| 10 | Function Overriding | Overrides a virtual member function in a derived class. |
| 11 | Abstract Class | Uses a pure virtual function to form an abstract base class. |
| 12 | Virtual Base Class and Diamond Inheritance | Demonstrates the diamond problem and virtual inheritance. |
| 13 | Friend Class | Demonstrates privileged access through a friend class. |
| 14 | Nested Class | Creates and uses a class nested inside another class. |
| 15 | Mini-Project - Vehicle Rental System | Models a vehicle-rental system using inheritance and overriding. |
| 16 | Mini-Project - Employee Payroll System | Builds a payroll system using an abstract employee interface and derived salary calculations. |
